# E-Commerce Website (V1)

A full-stack e-commerce application built as a learning project using **Angular**, **ASP.NET Core**, **SQL Server**, and **Redis**.

This repository contains the **first version (V1)** of the project, which implements the core e-commerce functionality using a traditional layered architecture. It serves as the foundation for future enhancements.

## Tech Stack

- Angular
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Redis
- Docker

## Features

- Product CRUD API
- SQL Server with Entity Framework Core
- Redis shopping basket
- RESTful API
- Dockerized SQL Server
- Dependency Injection
- Entity Framework Migrations

## Getting Started

1. Clone the repository.
2. Start SQL Server using Docker Compose.
3. Update the connection string in `appsettings.json`.
4. Run EF Core migrations.
5. Start the API and Angular frontend.
